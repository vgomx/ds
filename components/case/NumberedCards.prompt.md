NumberedCards — for a set of parallel points that each need a sentence or two.

```jsx
<NumberedCards minWidth={440} items={[
  { title: 'Implementation design is its own discipline', body: '…' },
  { title: 'Momentum is half the job', body: '…' },
]} />
```

Two to six cards. Raise `minWidth` (e.g. 440) for two-up takeaways; keep 260 for three- and four-up constraints.
