ReasoningChain — shows how one thing led to the next.

```jsx
<ReasoningChain steps={[
  { label: 'Hypothesis', text: 'A numbered progress indicator would help people keep going.' },
  { label: 'Finding', text: '…' },
  { label: 'Decision', text: '…' },
]} />
```

One sentence per step. In Research, the decision should point to a row in Solution; under a Solution decision, use Considered → Chose → Why for the trade-off.
